Check it yourself: the exact values by hand

You do not need to trust our software for the exact values. Each one follows from a one-line textbook argument, given here so a reviewer can confirm it independently.

Appendix: safe replacements

In a client audit, this appendix contains a short, readable drop-in replacement for each formula with its measured accuracy. Omitted from this public sample.

Method and validation

Exact values come from FMSL's proven one-variable and multivariable engines; nothing is estimated, and each is also derived by hand above. The safe replacements are short, readable functions (an exact value at the point, a polynomial near it, the original formula elsewhere) that can be reviewed line by line. Floating-point errors are measured, not proven. For points other than 0, the measured error also includes the rounding of the point itself. As a check of the audit itself, 16 of 16 results match the textbook closed forms.
